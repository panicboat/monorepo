# フィード・ランキング

ホームのフィードは、全国・エリア・フォロー中・フォロワーの 4 つのタブで表示する投稿を切り替える。
ランキングは、期間内に公開開始した、いいねされた公開投稿を累計いいね数で並べる。
キャスト・ゲストの両方が使う。

## Rules

### ホームのタブ

| タブ | 対象の投稿 | 閲覧者の条件 |
| --- | --- | --- |
| 全国（既定） | すべての投稿者の公開投稿 | 自分の投稿は公開範囲に関係なく含まれる |
| エリア | 自分のプロフィールの都道府県に属するプロフィールの投稿 | 都道府県が未設定なら取得せず、設定を促す表示になる。<br>自分の投稿は自分の都道府県に属するため含まれる |
| フォロー中 | 承認済みのフォロー先の投稿（公開範囲 private を含む） | 承認待ちのフォローは含まれない。<br>自分の投稿は含まれない |
| フォロワー | 承認済みのフォロワーの投稿 | 公開投稿、および相互フォローの private 投稿。<br>自分の投稿は含まれない |

- エリアの都道府県は、サーバーが閲覧者のプロフィールから決める。
  - リクエストに都道府県は含めない。
  - 都道府県が未設定のプロフィールでは、サーバーはエリアのフィードを返さずエラーで応える。
  - 画面は取得せずに、都道府県の設定を促す案内を出す。

### 全タブに共通の除外

| 状況 | 扱い |
| --- | --- |
| 表示期間外の投稿（公開開始より前、または終了時刻以降） | 含まれない |
| 閲覧者とブロック関係にある投稿者（どちらか一方向でも） | 含まれない |
| 無効化されたプロフィール・退会したアカウントの投稿 | 含まれない |
| 公開範囲 private の投稿 | 承認済みフォロワーと本人のみ含まれる |

### 並び順とページング

- 並び順は公開開始時刻の降順。
  - 同じ公開開始時刻は投稿 ID の降順。
- お知らせ投稿の公開開始時刻は、予定のお知らせ時刻と保存時刻のうち遅い方（[予定](schedules.md)）。
- 1ページの件数は既定 20 件。
  - 上限は 50 件。
- 次ページの cursor は、そのページ最後の投稿の（公開開始時刻, ID）。
- 公開範囲・無効化による除外は、フォロワーのタブを除き取得後に行われる。
  - 除外で 1 ページの件数に足りないときは、続きを取得して埋める。
  - 次ページが存在するかの判定は除外の後の件数で決まる。
- 読めない cursor と、ID が UUID の形でない cursor は、先頭ページとして扱う。

### 引用投稿

- 引用投稿は、通常の投稿と同じ規則でフィードに並び、除外される。
  - 引用元の投稿者や公開範囲は、引用投稿の掲載に影響しない。

### ランキング

| タブ | 対象期間（公開開始時刻で判定） |
| --- | --- |
| 24h | 現在から 24 時間前以降に公開開始した投稿 |
| 1週間（既定） | 現在から 7 日前以降に公開開始した投稿 |
| 全期間 | 期間の制限なし |

- 対象は公開投稿（公開範囲 public）かつ表示期間内の投稿で、いいねが 1 件以上あるもの。
- 順位はいいね数の降順。
  - 同数の場合は投稿 ID の降順。
  - いいね数は期間に関係なく、投稿の累計いいね数。
- コメント数は順位に使わない。
- 引用数も順位に使わない。
  - 引用投稿自身は、通常の投稿と同じく、いいねが付けば対象になる。
- 表示の除外は、ホームの「全タブに共通の除外」と同じ規則で行われる。
- 1ページの件数は既定 20 件、上限 50 件。
  - 除外した投稿の分は続きから補うため、最後のページ以外は件数どおりになる。
- 次ページの cursor は、そのページ最後の投稿の（いいね数, ID）。
  - 閲覧者に見えない投稿の ID といいね数は、cursor に入らない。

## Lifecycle

- 投稿は公開開始時刻から表示され、終了時刻に達するとフィード・ランキングから外れる。
- 24h ランキングは、公開開始から 24 時間ちょうどまで対象に含まれ、それを過ぎると外れる。
- 1週間ランキングも 7 日で同様。
- 同じ投稿でも、いいねが 0 件の間はランキングに現れない。
  - いいねが付いた後は、期間内であればいいね数に応じて順位が上がる。

## Interactions

- 投稿の公開範囲・ブロック・表示期間の規則は [投稿](posts.md) と [フォロー・ブロック](follows-and-blocks.md) に従う。
- お知らせ投稿は公開開始時刻で並ぶ（[予定](schedules.md)）。
- ホームの「カルテ」「クチコミ」タブはこのページの対象外。
  - フィードではないため。
- 引用枠と引用数の規則は [投稿](posts.md) に従う。
- 投稿の検索結果は公開範囲 public の投稿だけを対象とし、その他の除外規則はフィードと同じ（[検索](search.md)）。

## Data

- `post.posts`: 投稿（公開範囲・公開開始・終了時刻・投稿者）
- `post.likes`: いいね数の集計
- `social.follows`: 承認済みフォロー関係（フォロー中・フォロワー・private 投稿の閲覧判定）
- `social.blocks`: ブロック関係による除外
- `profile.profiles`: 都道府県（エリア）、無効化の状態
- `identity.accounts`: 退会の状態

カラム詳細は [data model](../data-model.md) を参照。

## Rationale

- エリアの都道府県は、リクエストで受け取らない。
  - タブの定義が閲覧者自身の都道府県であり、クライアントの指定と食い違う余地をなくすため。
- お知らせ投稿も、作成時刻ではなく公開開始時刻で並ぶ。
  - フィード全体の並び順に公開開始時刻を使うため。
- ランキングの期間は投稿の公開開始で区切り、いいね数は期間に関係なく累計で数える。
