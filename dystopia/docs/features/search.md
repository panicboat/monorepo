# 検索

ユーザー・投稿・予定を検索し、おすすめユーザーを表示する機能。
キャスト・ゲストの両方が使う。
検索には有効なプロフィールでのログインが必要で、投稿・予定・おすすめの結果は閲覧者との関係によって絞られる。

## Rules

### 検索画面のタブ

| タブ | 既定 | 検索語 |
| --- | --- | --- |
| ユーザー | 検索語が `#` または `＃` で始まらないとき | 名前（ユーザー名・表示名）の部分一致。<br>大文字小文字を区別しない |
| 投稿 | 検索語が `#` または `＃` で始まるとき | 本文の部分一致（大文字小文字を区別しない）。<br>`#` または `＃` に続けて 1 文字以上入力した場合はタグの完全一致（大文字小文字を区別しない）。<br>`#` または `＃` だけの検索語は、本文の部分一致として扱われる。 |
| 予定 | なし（予定タブを選んだとき） | 名前の部分一致。<br>先頭の `@` または `＠` は除く |

検索語が空の場合、ユーザーと投稿は結果を返さない。

### ユーザー検索

- 対象は無効化されていないプロフィール（退会したアカウントを除く）。
  - 非公開プロフィールも対象に含まれる。
- ブロック関係にあるプロフィールも対象に含まれる。
- ロールで絞り込める。
  - すべて・キャスト・ゲスト。
- 並び順は作成日時の降順、同じ場合はプロフィール ID の降順。
- 1 ページの既定は 20 件、上限は 50 件。
- 検索語の `%` と `_` は、ワイルドカードとして扱われる。

### 投稿検索

- 対象は公開範囲 public の投稿で、表示期間内のもの（[投稿](posts.md)）。
- 公開範囲 private の投稿は、閲覧者が承認済みフォロワーでも対象に含まれない。
- 結果の表示は [フィード・ランキング](feed-and-ranking.md) と同じ除外規則に従う。
  - ブロック関係の投稿者、無効化・退会した投稿者、非公開プロフィールで承認済みフォロワーでない閲覧者（本人を除く）の投稿は表示されない。
- 並び順は公開開始時刻の降順、同じ場合は投稿 ID の降順。
- 1 ページの既定は 20 件、上限は 50 件。

### 予定検索

| 条件 | 既定 | 絞り込みの規則 |
| --- | --- | --- |
| 日付 | 日本時間の今日 | 今日から 14 日間（今日を含む）から選ぶ。<br>範囲外の値は既定に戻る |
| 都道府県 | 自分のプロフィールの都道府県（未設定なら全国） | 全国を選ぶと都道府県は空になる |
| エリア | 自分のプロフィールのエリア（都道府県が空なら空） | 都道府県を選んだときのみ有効。<br>その都道府県のエリアに限定する |
| 業種 | 全業種 | 業種名の完全一致 |
| 時間帯 | すべて | 予定の時間帯が次の区間と重なるもの。<br>昼 5:00〜18:00、夜 18:00〜21:00、深夜 21:00〜翌 5:00。<br>区間は始点を含み終点を含まない |
| フォロー中だけ | オフ | オンのとき、承認済みのフォロー先のキャストに限定する |
| 名前 | 空 | 名前の部分一致 |

- 対象はキャストのプロフィール（ゲストの予定は対象外）。
- 対象は選んだ日付の予定を持つキャストのみ。
  - その日に予定の行がないキャストは出ない。
- 無効化されたプロフィール・退会したアカウントは出ない。
- ブロック関係（どちらか一方向でも）にあるキャストは出ない。
- 非公開プロフィールのキャストも出る。
  - ひとことは、閲覧者がそのお知らせを見られる場合のみ表示される（[予定](schedules.md)）。
- 並び順は予定の開始時刻の昇順。
  - 開始が 00:00〜04:59 の予定は、同じ日付の中で最後にまとめられる。
  - 同じ開始時刻はプロフィール ID の昇順。
- 1 ページの既定は 20 件、上限は 50 件。

### おすすめユーザー

- 閲覧者のロールの反対のロールを表示する。
  - キャストにはゲスト、ゲストにはキャストを表示する。
- 除外するもの: 自分自身、承認済みのフォロー先、ブロック関係（どちらか一方向でも）にあるプロフィール、無効化・退会したプロフィール。
  - 承認待ちのフォロー先は除外されない。
- 並び順は作成日時の降順。
- 1 ページの既定は 10 件、上限は 50 件。

### 検索結果に出ない条件

| 条件 | ユーザー | 投稿 | 予定 | おすすめ |
| --- | --- | --- | --- | --- |
| 無効化されたプロフィール・退会したアカウント | 出ない | 出ない | 出ない | 出ない |
| ブロック関係（どちらか一方向でも） | 出る | 出ない | 出ない | 出ない |
| 非公開プロフィール（承認済みフォロワーと本人以外） | 出る | 出ない | 出る（ひとことは空） | 出る |
| 公開範囲 private の投稿 | — | 出ない（承認済みフォロワーでも） | — | — |
| 表示期間外の投稿（予告中・終了後） | — | 出ない | — | — |
| ゲストのプロフィール | 出る（ロール「ゲスト」で絞り込める） | — | 出ない（キャストのみ対象） | キャストの閲覧者には出る。<br>ゲストの閲覧者には出ない |

## Interactions

- 検索結果の投稿の表示規則は [投稿](posts.md) と [フィード・ランキング](feed-and-ranking.md) に従う。
- 予定検索の結果は [予定](schedules.md) の予定とお知らせに従う。
- フォロー・ブロックの状態は [フォロー・ブロック](follows-and-blocks.md) の規則で検索結果に作用する。
  - ユーザー検索はブロックを除外しない。
- 結果のプロフィールカードは [プロフィール](profiles.md) の表示規則に従う。

## Data

- `profile.profiles`: 名前、都道府県・エリア、非公開設定、無効化の状態
- `profile.casts`: 業種
- `identity.accounts`: ロール（キャスト・ゲスト）、退会の状態
- `schedule.schedules`: 予定検索の対象行（日付・時刻・お知らせ投稿の紐づけ）
- `post.posts`: 投稿検索の対象となる投稿、予定検索のひとこと（お知らせ投稿の本文）
- `post.hashtags`: タグ検索
- `social.follows`: フォロー中の絞り込み、承認済みフォロワー判定、おすすめの除外
- `social.blocks`: ブロック関係による除外

カラム詳細は [data model](../data-model.md) を参照。
