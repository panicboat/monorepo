# ブックマーク

キャストとゲストが、閲覧できる [投稿](posts.md) を自分のプロフィールに保存して、あとから一覧で開く機能。
対象は投稿だけで、一覧は表示中のプロフィール単位。

## Rules

### 追加・一覧・状態の判定

投稿の状況ごとに、追加・一覧・ブックマーク状態の扱いを次の表で決める。
投稿の閲覧条件は [投稿](posts.md) と [フォロー・ブロック](follows-and-blocks.md) に従う。

| 投稿の状況 | 追加 | 一覧 | ブックマーク状態 |
|---|---|---|---|
| 自分が作成した投稿 | 可 | 表示 | ブックマーク済み |
| 公開時刻より前、または期限切れ | 不可 | 非表示 | 未ブックマーク扱い |
| 作成者のプロフィールが取得できない | 不可 | 非表示 | 未ブックマーク扱い |
| 作成者とブロック関係がある（どちら向きでも） | 不可 | 非表示 | 未ブックマーク扱い |
| フォロワーのみの投稿で、作成者への承認済みフォローがない | 不可 | 非表示 | 未ブックマーク扱い |
| 投稿が存在しない | 不可 | 非表示 | 未ブックマーク扱い |
| 上記以外 | 可 | 表示 | ブックマーク済み |

- 追加は 1 組（プロフィール・投稿）につき 1 件。
  - すでにある投稿を追加しても、閲覧できる投稿なら成功扱いで、件数は増えない。
    - 閲覧できない投稿は、行が残っていても追加は 404 で失敗する。
- 解除は投稿の閲覧可否に関係なくいつでもできる。
- 非表示の間もブックマークの行は残る。
  - 再び閲覧できる状態に戻ると、一覧と状態に戻る。
- 投稿が存在しなくなった場合も行は残り、一覧には出ない。

### 一覧

- 自分のブックマークだけを、追加時刻の降順で表示する。
- 1 ページは既定 20 件、上限 50 件。
- 1 ページの件数が上限より少なくなることがある。
  - 非表示の行はページ内で取り除かれるため。
  - 続きの有無は行数で判定する。

## Lifecycle

- 追加 → 一覧に表示される → 閲覧条件を満たさなくなると非表示になり、状態も未ブックマーク扱いになる → 閲覧条件を満たすと再び表示される。
- 解除すると行が消える。
- プロフィール削除で、そのプロフィールの行はすべて消える。

## Interactions

- 投稿の閲覧条件は、投稿の公開・期限・作成者の状態・ブロック・フォローに従う。
  - 詳細は [投稿](posts.md)、[フォロー・ブロック](follows-and-blocks.md)。
- プロフィール削除時は、そのプロフィールのブックマークを削除する。
  - 詳細は [プロフィール](profiles.md)。

## Data

- `bookmarks.bookmarks` — プロフィールと投稿の組、追加時刻
