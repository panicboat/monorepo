# クチコミ

ゲストがキャストについて書く評価と出来事の記録。書けるのはゲストだけで、閲覧はキャスト・ゲストの両方ができる。一覧に出るかどうかは、書き手と対象の有効性、双方向ブロック、対象の公開設定で決まる。

## Rules

### 作成

- 書けるのはゲストのアカウントだけ。
- 対象は有効なキャストのプロフィールに限る。ゲストのプロフィール、無効化されたプロフィール、退会済みアカウントのプロフィール、存在しないプロフィールは拒否する。
- 同じアカウントのプロフィールは対象にできない。
- 作成時のブロック確認はない。対象が非公開でも、フォローしていなくても作成できる。

### 閲覧

書き手または対象のどちらかが無効化されている、または退会済みのクチコミは、どの閲覧者からも見えない。両当事者が有効なクチコミについて、閲覧者ごとの条件は次の通り。

| 閲覧者 | 双方向ブロック | 対象キャストの公開設定 | 閲覧 |
|---|---|---|---|
| 書き手アカウント（同じアカウントの別プロフィールを含む）、自分のクチコミの詳細と一覧を見る場合 | 無関係 | 無関係 | 可 |
| 対象キャスト本人のプロフィール | 無関係 | 無関係 | 可 |
| その他のアカウント | ブロック関係があれば不可 | 非公開なら承認済みフォローが必要 | 両条件を満たせば可 |

- 対象キャストの一覧では、閲覧者が書き手をブロックしている、または書き手にブロックされているクチコミは一覧から外れる。
- ゲストのプロフィールのクチコミ一覧（書いたクチコミの一覧）は、閲覧者がそのゲストに到達できる場合だけ表示される。到達できるのは、ゲストが公開、または承認済みフォローがある場合。
- 最近のクチコミ（ホーム）は、対象キャストに到達でき、どちらの当事者ともブロック関係がないクチコミだけを返す。
- 自分のクチコミ一覧と件数（総数・未評価数）は、自分のアカウントのクチコミのうち両当事者が有効なものを数える。件数は先頭ページだけで返る。

### 評価と平均

- 評価は 1〜5 の整数。0 または未指定は未評価。
- 平均評価は、対象キャストへのクチコミのうち評価済みのものを書き手プロフィールごとに平均し、その平均の平均で求める。評価者数は評価した書き手プロフィールの数で、同じアカウントの複数プロフィールは別々に数える。未評価のクチコミは平均にも評価者数にも含まれない。
- 平均は閲覧者に関係なく同じ値。ブロック関係にある書き手の評価も含まれる。
- 書き手が無効化されていても、そのクチコミの評価は平均に含まれる。書き手プロフィールが削除されると、その評価は平均から消える。
- 対象キャストが無効化されている場合、一覧は空で、平均評価は 0、評価者数は 0、件数は 0 になる。

### 編集・評価・削除

- 作者アカウントだけが実行できる。同じアカウントの別プロフィールからも実行できる。
- 両当事者が有効であることが必要。対象キャストが無効化されたクチコミは、作者からも見えず、編集・評価・削除は「見つからない」扱いになる。

## Lifecycle

作成 → 出来事の追加・編集・削除、評価の設定 → 最後の出来事の削除で消滅、の順に状態が進む。期限で閉じる状態はない。

- 作成: 初回の出来事が必須。クチコミと出来事を同じ処理で保存する。活動日時は作成時刻になる。
- 出来事の追加: 作者だけが実行できる。活動日時を現在時刻にする。対象キャストの一覧は活動日時の降順なので、追加したクチコミが先頭に来る。
- 出来事の編集と評価の設定: 活動日時は変わらず、更新日時だけが変わる。
- 出来事の削除: 残りが 2 件以上あれば、その出来事だけを消す。残り 1 件の出来事を消すと、クチコミ全体が消える。
- 出来事の日付: 日本時間の今日以前、`YYYY-MM-DD` 形式だけを受け付ける。最終出来事日は出来事の日付の最大値に追従し、最近のクチコミ（ホーム）の並び順の基準になる。並びは最終出来事日、作成日時、IDの降順。
- 出来事の備考: 500 文字以下。空白だけの備考は保存されない。備考が必須なのは、`reservation` の `cast_no_show`、`service` の `ended_early`、`aftercare` の `trouble_occurred`。
- 対象キャストが無効化されると、そのキャストのクチコミは一覧・平均・個別表示から消える。有効に戻すと再び見える。
- 書き手プロフィールが無効化または退会すると、そのクチコミは全閲覧者から消える。平均には残る。
- 書き手プロフィールが削除されると、そのプロフィールが書いたクチコミと、そのプロフィール宛てのクチコミが、出来事とともに全部消える。平均からも消える。
- 退会したアカウントが purge されると、そのアカウントの各プロフィールに対して削除と同じ処理が走る。

## Interactions

- [プロフィール](profiles.md): プロフィールの削除で、そのプロフィールが書いた・受けたクチコミが消える。無効化は閲覧と平均の条件に効く。
- [フォロー・ブロック](follows-and-blocks.md): 双方向ブロックは一覧と個別表示から除外する。ブロックしても平均からは除外されない。承認済みフォローは非公開キャストのクチコミの閲覧条件になる。
- [アカウント](account.md): 退会後の purge で、そのアカウントのプロフィールのクチコミが消える。
- 画面:
  - ホームの「クチコミ」タブは全ロールに表示される。
  - 下部ナビの「クチコミ」はゲストだけに表示される。
  - キャストのプロフィールには「クチコミ」タブが表示され、対象キャストへのクチコミと平均を見られる。
  - ゲストのプロフィールには「クチコミ」タブが表示され、そのゲストが書いたクチコミを見られる。

## Data

- `review.reviews`: クチコミ本体。作者アカウント、作者プロフィール、対象プロフィール、評価、最終出来事日、活動日時を持つ。
- `review.events`: クチコミの出来事。クチコミ削除に連動して消える。
- `identity.accounts`: アカウントのロール。ゲスト・キャストの判定と、退会の判定に使う。
- `profile.profiles`: 書き手と対象のプロフィールの有効性。
- `social.blocks`: 双方向ブロックの判定。
- `social.follows`: 非公開キャストの閲覧条件となる承認済みフォローの判定。

カラムの詳細は [data model](../data-model.md) を参照。
