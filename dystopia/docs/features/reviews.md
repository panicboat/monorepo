# クチコミ

ゲストがキャストについて書く評価と出来事の記録。書けるのはゲストだけで、閲覧はキャスト・ゲストの両方ができる。一覧に出るかどうかは、当事者の有効性、双方向ブロック、公開設定で決まる。書き手のゲストや対象のキャストがプロフィールの削除・無効化・退会をしても、クチコミは残る。

## Rules

### 作成

- 書けるのはゲストのアカウントだけ。
- 対象は有効なキャストのプロフィールに限る。ゲストのプロフィール、無効化されたプロフィール、退会済みアカウントのプロフィール、存在しないプロフィールは拒否する。
- 同じアカウントのプロフィールは対象にできない。
- 作成時のブロック確認はない。対象が非公開でも、フォローしていなくても作成できる。

### 閲覧

「有効」は、プロフィールが無効化されておらず、アカウントが退会中でなく、削除・purge されていない状態を指す。クチコミは当事者が有効でなくなっても消さず、有効でない側を名前を伏せて表示する。場面ごとに出る条件は次の通り。

| 場面 | 出る条件 |
|---|---|
| 対象キャストのクチコミ一覧 | 対象キャストが有効で、閲覧者が対象キャストに到達できること。書き手の状態は問わない。閲覧者が書き手をブロックしている、または書き手にブロックされているクチコミは外れる |
| ゲストの「書いたクチコミ」一覧 | ゲストが有効で、閲覧者がそのゲストに到達できること。対象キャストが有効なら、閲覧者が対象キャストにも到達できること。対象キャストが有効でなければ、対象を伏せて出る。閲覧者が対象キャストをブロックしている、または対象キャストにブロックされているクチコミは外れる |
| 最近のクチコミ（ホーム） | 対象キャストが有効で、閲覧者が対象キャストに到達でき、書き手と対象のどちらともブロック関係がないこと。書き手の状態は問わない |
| 個別表示（作者アカウント） | 常に開ける。同じアカウントの別プロフィールで開く場合も同じ |
| 個別表示（対象キャスト本人） | 対象キャストが有効なら開ける |
| 個別表示（その他の閲覧者） | 閲覧者が見られるいずれかの一覧（対象キャストのクチコミ一覧、ゲストの「書いたクチコミ」一覧、最近のクチコミ）に出るなら開ける。出ないものは URL で直接開いても「見つからない」扱い |
| 自分のクチコミ一覧と件数 | 作者アカウントが書いたものすべて。当事者の状態は問わない。件数（総数・未評価数）は先頭ページだけで返る |

- 到達できるのは、公開されているプロフィール、または承認済みフォローがあるプロフィール。
- 対象キャスト本人は、自分へのクチコミの一覧を、ブロック関係と公開設定に関係なく見られる。
- 書き手と対象の両方が有効でない場合、クチコミはどの一覧にも出ない。作者アカウントの自分のクチコミ一覧と個別表示だけに残る。
- 有効でない当事者は、表示名・ユーザー名・アバター・プロフィールへのリンクを出さない。削除済み・無効化・退会中は区別しない。
- 書き手のゲストは「（無効なゲスト）」、対象のキャストは「（無効なキャスト）」と表示する。クチコミは書き手がゲスト、対象がキャストと決まっているため、役割で出し分ける。
- アバターは画像なしで、頭文字は「?」。有効でない対象キャストのユーザー名（「@...」）の併記も出さない。
- 自分のクチコミ一覧で、使用中でないプロフィールで書いたものには「@ユーザー名 として記録」を付ける。そのプロフィールが有効でなければ「（無効なゲスト）として記録」になる。

### 評価と平均

- 評価は 1〜5 の整数。0 または未指定は未評価。
- 平均評価は、対象キャストへのクチコミのうち評価済みのものを書き手プロフィールごとに平均し、その平均の平均で求める。評価者数は評価した書き手プロフィールの数で、同じアカウントの複数プロフィールは別々に数える。未評価のクチコミは平均にも評価者数にも含まれない。
- 平均は閲覧者に関係なく同じ値。ブロック関係にある書き手の評価も含まれる。
- 書き手の状態（無効化・退会中・削除・purge）にかかわらず、そのクチコミの評価は平均と評価者数に含まれる。
- 対象キャストが有効でない（無効化・退会中・削除済み）場合、一覧は空で、平均評価は 0、評価者数は 0、件数は 0 になる。

### 編集・評価・削除

- 作者アカウントだけが実行できる。同じアカウントの別プロフィールからも実行できる。
- 当事者の状態は条件にしない。対象キャストや書き手のプロフィールが有効でなくても、作者は自分のクチコミを編集・評価・削除できる。当事者の状態に左右されず、作者がいつでも自分のクチコミを削除できるようにするため。

## Lifecycle

作成 → 出来事の追加・編集・削除、評価の設定 → 最後の出来事の削除で消滅、の順に状態が進む。期限で閉じる状態はない。

- 作成: 初回の出来事が必須。クチコミと出来事を同じ処理で保存する。活動日時は作成時刻になる。
- 出来事の追加: 作者だけが実行できる。活動日時を現在時刻にする。対象キャストの一覧は活動日時の降順なので、追加したクチコミが先頭に来る。
- 出来事の編集と評価の設定: 活動日時は変わらず、更新日時だけが変わる。
- 出来事の削除: 残りが 2 件以上あれば、その出来事だけを消す。残り 1 件の出来事を消すと、クチコミ全体が消える。
- 出来事の日付: 日本時間の今日以前、`YYYY-MM-DD` 形式だけを受け付ける。最終出来事日は出来事の日付の最大値に追従し、最近のクチコミ（ホーム）の並び順の基準になる。並びは最終出来事日、作成日時、IDの降順。
- 出来事の備考: 500 文字以下。空白だけの備考は保存されない。備考が必須なのは、`reservation` の `cast_no_show`、`service` の `ended_early`、`aftercare` の `trouble_occurred`。
- クチコミの行が消えるのは、作者が削除したとき（最後の出来事を消したときを含む）だけ。
- プロフィールの削除・purge でクチコミは消えない。書いたものも、そのプロフィールについて書かれたものも残り、有効でない当事者は役割つきの伏せた名前で表示される。退会したアカウントが purge されたときも同じ。
- 対象キャストが有効でなくなると、そのキャストのクチコミ一覧は空になり、平均は 0 になり、最近のクチコミからも外れる。書き手のゲストが有効なら、「書いたクチコミ」一覧と個別表示には対象を伏せて残る。対象キャストが有効に戻ると、元どおり見える。
- 書き手のゲストが有効でなくなっても、対象キャストが有効なら、そのクチコミは書き手を伏せて対象キャストの一覧・最近のクチコミ・個別表示に残り、平均にも含まれる。ゲストの「書いたクチコミ」一覧はゲストのページがないので出ない。

## Interactions

- [プロフィール](profiles.md): プロフィールの削除でクチコミは消えない。無効化・削除・退会は、閲覧と平均の条件と、当事者の伏せた表示に効く。
- [フォロー・ブロック](follows-and-blocks.md): 双方向ブロックは一覧と個別表示から除外する。ブロックしても平均からは除外されない。承認済みフォローは非公開キャストのクチコミの閲覧条件になる。書き手のプロフィールが削除・purge されるとブロックの行も消えるため、そのゲストをブロックしていた閲覧者にも、書き手を伏せたクチコミが見える。
- [アカウント](account.md): 退会後の purge でもクチコミは消えない。
- 画面:
  - ホームの「クチコミ」タブは全ロールに表示される。
  - 下部ナビの「クチコミ」はゲストだけに表示される。
  - キャストのプロフィールには「クチコミ」タブが表示され、対象キャストへのクチコミと平均を見られる。
  - ゲストのプロフィールには「クチコミ」タブが表示され、そのゲストが書いたクチコミを見られる。

## Data

- `review.reviews`: クチコミ本体。作者アカウント、作者プロフィール、対象プロフィール、評価、最終出来事日、活動日時を持つ。プロフィールの削除・purge のあとも行が残り、作者アカウントとプロフィールの ID は参照先がなくなっても残る。
- `review.events`: クチコミの出来事。クチコミ削除に連動して消える。
- `identity.accounts`: アカウントのロール。ゲスト・キャストの判定と、退会の判定に使う。
- `profile.profiles`: 書き手と対象のプロフィールの有効性。
- `social.blocks`: 双方向ブロックの判定。
- `social.follows`: 非公開キャストの閲覧条件となる承認済みフォローの判定。

カラムの詳細は [data model](../data-model.md) を参照。
