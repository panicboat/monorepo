# カルテ

キャストが対象ゲストについて記録する機能。
カルテは評価と出来事（予約・施術・アフターケアの段階ごとの記録）から成る。
使うのはキャストだけで、ゲストはカルテを閲覧も操作もできない。

## Rules

閲覧と操作の権限はアカウントのロールと作者アカウントで判定する。
プロフィールの公開設定とブロック関係は、カルテの閲覧にも作成にも条件として入らない。

| 閲覧者 | 閲覧 | 作成 | 出来事・評価・カルテの編集と削除 |
|---|---|---|---|
| 作者アカウント（同じアカウントの別プロフィールを含む） | 可 | 可 | 可 |
| 別のキャストのアカウント | 可（全キャストのカルテ） | 可 | 不可 |
| ゲストのアカウント（対象ゲスト本人を含む） | 不可 | 不可 | 不可 |

- 作成: 対象は有効なゲストのプロフィールに限る。
  - キャストのプロフィール、無効化されたプロフィール、アカウントが退会済みのプロフィール、存在しないプロフィールは拒否する。
- 作成時に記録される作者プロフィールは、カルテの閲覧者に表示される。
  - 作者アカウントは表示されず、閲覧者本人のカルテかどうかだけが分かる。
- 出来事の段階は `reservation`、`service`、`aftercare` の 3 つ。
- 結果とタグは段階ごとに決まった値だけを受け付け、同じタグは 1 出来事に 1 回だけ付けられる。
- 出来事の備考は 500 文字以下。
- 空白だけの備考は保存されず、備考なしとして扱われる。
- 次の結果は備考が必須: `reservation` の `no_show`、`service` の `ended_early`、`aftercare` の `trouble_occurred`。
- 出来事の日付は `YYYY-MM-DD` 形式で、日本時間の今日以前だけを受け付ける。
- 評価は 1〜5 の整数。
  - 0 または未指定は評価なし（未評価）。
- 評価は作者だけが設定・消去できる。
- 対象ゲストの集計（平均評価・評価者数・評価済みカルテ数）は、キャストの一覧画面でだけ返る。
  - 作者プロフィールごとに評価済みカルテの平均を求め、その平均の平均を平均評価とする。
  - 評価者数は評価したプロフィールの数で、同じアカウントの複数プロフィールは別々に数える。
  - 未評価のカルテは集計に含まれない。
- 集計はカルテの作者プロフィールが無効化・削除されていても、残っているカルテの評価を含める。

## Lifecycle

作成 → 出来事の追加・編集・削除、評価の設定 → 削除、の順に状態が進む。
期限で閉じる状態はない。

- 作成: 初回の出来事が必須。
  - カルテと出来事を同じ処理で保存し、活動日時を作成時刻に設定する。
- 出来事の追加: 作者だけが実行できる。
  - 活動日時を現在時刻にする。
  - 追加したカルテは対象ゲストの一覧の先頭に来る。
    - 活動日時が一覧の並び順の基準になるため。
- 出来事の編集と評価の設定: 活動日時は変わらず、更新日時だけが変わる。
- 出来事の削除: 残りが 2 件以上あれば、その出来事だけを消す。
  - 残り 1 件の出来事を消すと、カルテ全体が消える。
- カルテの最終出来事日は、出来事の日付の最大値に追従する。
  - 追加・編集・削除のたびに再計算する。
  - 最近のカルテ一覧はこの日付で並ぶ。
- 削除: 作者だけが実行できる。
  - 出来事も同時に消える。
- 対象ゲストのプロフィールが無効化されても、カルテは残り、キャストの一覧に表示され続ける。
  - 対象の表示情報は返らず、対象は「（無効なゲスト）」と表示される。
- 作者のプロフィールが削除されても、カルテは残る。
  - 作者の表示情報は返らず、作者は「（無効なキャスト）」と表示される。
- 自分のカルテ一覧で、使用中でないプロフィールで書いたものには「@ユーザー名 として記録」を付け、そのプロフィールが有効でなければ「（無効なキャスト）として記録」になる。
- 作者のアカウントが退会後に purge されても、カルテは消えない。

## Interactions

- プロフィール: プロフィールの削除でカルテは消えない。
  - 対象と作者の表示名などは [プロフィール](profiles.md) の要約情報を使い、要約が取れないプロフィールは空で返る。
- フォロー・ブロック: カルテの閲覧と作成に影響しない。
  - ブロックしていてもキャストはゲストのカルテを作成でき、他のキャストはそのカルテを閲覧できる。
  - [フォロー・ブロック](follows-and-blocks.md) を参照。
- 他機能: カルテを参照する処理は、通知・検索・フィード・メッセージのいずれにもない。
- 画面: ホームの「カルテ」タブと下部ナビの「カルテ」はキャストだけに表示される。
  - キャストの閲覧者がゲストのプロフィールを開くと「カルテ」タブが表示され、対象ゲストのカルテ一覧と集計を見られる。

## Data

- `karte.kartes`: カルテ本体。
  - 作者アカウント、作者プロフィール、対象プロフィール、評価、最終出来事日、活動日時を持つ。
- `karte.events`: カルテの出来事。
  - カルテ削除に連動して消える。
- `identity.accounts`: アカウントのロール。
  - キャストかどうかの判定に使う。
- `profile.profiles`: 対象と作者のプロフィールの有効性と表示情報。

カラムの詳細は [data model](../data-model.md) を参照。

## Rationale

- 集計は作者アカウントではなく作者プロフィール単位で行う。
  - アカウントの紐付きを隠すことを、アカウント単位の集計より優先した。
