# 通報

利用者が、他の利用者の投稿やふるまいを運営者に知らせる機能。
通報は貯めるだけで、自動の非表示や判定はしない。
運営者は DB を見て、未対応の通報に規約の「違反への措置」で対応する。

## Rules

### 通報できるもの

対象ごとに、通報できる条件を次の表で決める。

| 対象 | 条件 |
| --- | --- |
| 投稿 | 表示中のプロフィールが閲覧できる（[投稿](posts.md)） |
| コメント・返信 | 付いている投稿を、表示中のプロフィールが閲覧できる |
| DM | 表示中のプロフィールがスレッドの当事者である |
| クチコミ | 表示中のプロフィールが閲覧できる（[クチコミ](reviews.md)） |
| カルテ | キャストのアカウントである（[カルテ](karte.md)） |
| プロフィール | 有効である。<br>ブロックしている相手も通報できる |

- 条件を満たさないとき、または対象がないときは拒否する（404）。
- 同じアカウントのプロフィールが書いたものは通報できない（400）。

### 入力

- 理由は必須で、誹謗中傷・脅迫・つきまとい・嫌がらせ・その他から選ぶ。
  - 選択肢は利用規約の禁止事項の言葉に合わせる。
- 補足は任意で、200 文字まで。

### 通報の後

- 通報した人には、受け付けたことだけを表示する。
  - 対応の結果は知らせない。
- 通報された人には何も知らせない。
- 同じプロフィールが同じ対象をもう一度通報しても、行は増えず、最初の内容が残る。
  - 画面の表示は同じ。
- 通報の回数に上限はない。
  - 運営者が読むだけで、処理の費用がかからないため。

### 保存する内容

- 通報した人のアカウントとプロフィール、通報された人のアカウントとプロフィール、対象、理由、補足を保存する。
- 通報した時点の対象の本文を写して保存する。
  - 対象が消えたり書き換えられたりすると、運営者が確認できなくなるため。
  - クチコミとカルテは、評価と出来事を写す。
  - プロフィールは、表示名と自己紹介を写す。
  - 画像と動画は写さない。

## Lifecycle

- 通報 → 未対応のまま貯まる → 運営者が確認して対応する。
- プロフィールの削除やアカウントの削除処理でも、通報は消えない（[アカウント](account.md)）。
  - 規約の上では「申出」にあたり、プライバシーポリシーの「保存期間と削除」の節に定めている。

## Interactions

- フォロー・ブロック: ブロック関係にある相手の投稿は閲覧できないので通報できないが、プロフィールは通報できる。
  - 詳細は [フォロー・ブロック](follows-and-blocks.md)。
- メッセージ: 運営者が DM の内容を確認するのは、利用規約の「DM」の条に定める申出への対応にあたる。
  - 詳細は [メッセージ](messages.md)。

## Data

- `report.reports` — 通報した人と通報された人、対象、理由、補足、対象の内容の写し、対応した日時

## Rationale

- 自動の処置は持たない。
  - 実際の通報が貯まるまで、判定の基準を決める材料がないため。
- 管理画面は持たない。
  - 通報の確認と対応は DB を直接見て行う。
