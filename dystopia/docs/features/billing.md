# 課金

キャストとゲストのアカウントが、ロールごとの有料プランを Stripe で購読し、購読状態を管理するための機能。

**未稼働（本番環境から Stripe に到達できないため動かない）。** 以下はコード上の構成のみを記す。

## Rules

- 価格: アカウントのロールで決まる。ゲストは専用の価格、キャストは専用の価格を使う。ゲストとキャスト以外のロールは購読できない。
- チェックアウト: 有効な購読（状態が trialing または active で、期間終了が現在より後）があるアカウントは作成できない。Stripe の顧客は初回だけ作成し、以後は再利用する。成功時と中断時の戻り先は設定値。
- カスタマーポータル: Stripe の顧客があるアカウントだけ作成できる。戻り先は設定値。
- ウェブフック: Stripe からの通知を受ける。署名がない、または検証に失敗すると 400 を返す。処理に失敗すると 500 を返し、Stripe に再送させる。同じイベント id は 2 回目以降を無視する。
- 購読状態の同期: 購読の作成・更新で状態と期間終了を保存する。削除されたら canceled にする。一度 canceled になった購読は、後から届いた更新イベントで戻らない。チェックアウト完了と試用期間終了の通知は処理しない。
- 定期照合: 顧客ごとに保存済みの購読と Stripe の状態を比べ、差があれば保存済みの状態を更新する。
- フロントエンドに課金の画面と呼び出し口はない。

## Interactions

- ロールは [アカウント](account.md) のロールを使う。

## Data

- `billing.customers` — アカウントと Stripe の顧客 id の対応
- `billing.subscriptions` — 購読の状態、価格、期間終了、解約日時
- `billing.stripe_events` — 受け取ったウェブフックイベントと処理結果
